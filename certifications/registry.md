# ACP Certification Registry

This registry lists organizations that have received **Active Cyber Program (ACP) Certification**.

The registry provides transparency regarding organizations that have successfully demonstrated an **active cybersecurity program** according to the ACP framework.

Only certifications issued by **Wechsler Information Solution** are considered valid ACP certifications.

# Status Values

| Status    | Meaning                                                                                   |
| --------- | ----------------------------------------------------------------------------------------- |
| Valid     | The certification is valid and the ACP Trust Label may be used.                           |
| Suspended | The certification is temporarily suspended. The ACP Trust Label must not be used.         |
| Withdrawn | The certification has been withdrawn. The ACP Trust Label must not be used.               |
| Expired   | The validity period has ended without reassessment. The ACP Trust Label must not be used. |

Suspension and withdrawal rules are defined in `docs/certification.md`.

---

# Certification Validity

ACP certifications are valid for **24 months** from the certification date.

Organizations may undergo reassessment to maintain certification.

# Verification

Organizations, customers, and partners may consult this registry to verify whether an organization holds a valid **Active Cyber Program Certification**.

Only certifications listed with the status **Valid** are valid. A certificate ID shown on an ACP Trust Label must match an entry in this registry.

To confirm a specific certificate ID, contact [training@videotrainer.ch](mailto:training@videotrainer.ch).
