# ACP Trust Label

The **ACP Trust Label** allows organizations to publicly demonstrate that they operate an **Active Cyber Program (ACP)**.

The label communicates that the organization has successfully completed an ACP assessment and holds a valid **ACP Certification**.

---

# Label Purpose

The ACP Trust Label helps organizations:

* demonstrate cybersecurity maturity
* build trust with customers and partners
* communicate security posture
* support supplier security requirements

---

# Label Variants

## ACP Certified

Indicates that an organization holds a valid **Active Cyber Program Certification**.

Only organizations listed with the status **Valid** in the ACP Certification Registry may use this label.

## ACP Partner

Indicates an organization authorized to perform ACP assessments under a partner agreement with Wechsler Information Solution (see `docs/governance.md`).

The ACP Partner label does not indicate that the partner organization itself is ACP certified.

There is no label for organizations that have completed an assessment without receiving certification.

---

# Label Design

The label template is provided in `assets/acp-trust-label.svg`.

Each ACP Certified label must show:

* the **certificate ID** (for example ACP-2026-001)
* the **valid-until date**
* a reference to the ACP Certification Registry for verification

The label does not show scores, star ratings or maturity levels. ACP Certification confirms that the certification requirements are met; it is not a rating.

---

# Label Usage Rules

Organizations may display the ACP Trust Label on:

* corporate websites
* marketing material
* security documentation
* customer security responses

Where technically possible, the label should link to the ACP Certification Registry.

The label must not be modified, except for entering the certificate ID and valid-until date, and must not be used in a misleading way. It may only be used for the organizational units within the certified scope.

Detailed usage rules are defined in `docs/trademark.md`.

---

# Certification Validity

The ACP Trust Label may only be used while the ACP Certification is valid.

The label must not be used during a suspension. After withdrawal or expiration, the label must be removed from all materials within 30 days.
