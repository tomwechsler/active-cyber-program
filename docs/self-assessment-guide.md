# ACP Self-Assessment Guide

This guide explains how organizations can apply the **Active Cyber Program (ACP)** framework independently to evaluate and improve their cybersecurity program.

The goal is to help organizations perform a **structured self-assessment** and prepare for a potential ACP certification.

---

# Recommended Start: ACP Self-Assessment Web App

The easiest way to perform a self-assessment is the free web app at [acp.videotrainer.ch](https://acp.videotrainer.ch/) (in German). It guides you through all ACP controls with guiding questions and scoring guidance and shows the result immediately. No registration is required and no data is stored; all entries remain in your browser.

The web app reflects your own judgement and does not review evidence. If you are preparing for an ACP Certification, follow the steps below and collect evidence for each control as well.

---

# Overview

The ACP self-assessment consists of the following steps:

1. Define Scope
2. Identify Stakeholders
3. Collect Information
4. Perform Assessment
5. Gather Evidence
6. Score Results
7. Identify Gaps
8. Define Improvement Actions

---

# 1. Define Scope

Define what part of the organization will be assessed.

This may include:

• entire organization  
• specific business units  
• IT systems or environments  
• cloud or on-premise infrastructure  

A clearly defined scope ensures meaningful results.

---

# 2. Identify Stakeholders

Identify key stakeholders involved in cybersecurity.

Typical roles include:

• IT management  
• security responsible persons  
• system administrators  
• business representatives  

---

# 3. Collect Information

Gather relevant documentation and information.

Examples:

• policies and procedures  
• system documentation  
• architecture diagrams  
• security reports  

---

# 4. Perform Assessment

Start with the organization profile in the ACP assessment questionnaire (`assessment/assessment-questionnaire.md`, German version `assessment/assessment-questionnaire.de.md`). Then evaluate each domain. The guiding questions and the scoring guidance help determine one score per control.

Be honest with yourself: the scoring guidance shows what typically distinguishes score 2 from score 3. If a control has several parts, the weakest essential part determines the score. If your IT is operated by a service provider, involve the provider in the assessment.

For each control:

• review current implementation  
• discuss with relevant stakeholders  
• document findings  

---

# 5. Gather Evidence

Collect evidence supporting each assessment result.

Examples:

• policies  
• system configurations  
• screenshots  
• logs and reports  

Without evidence, a control is scored 0 – Not Implemented.

Small organizations do not need extensive documentation. Short, clear rules are sufficient if they are applied in practice and can be shown.

---

# 6. Score Results

Apply the ACP scoring model:

0 – Not Implemented  
1 – Partially Implemented  
2 – Implemented  
3 – Actively Managed  

Calculate:

• control scores  
• domain scores  
• overall ACP score  

Mark the AI Security domain as not applicable if no AI systems are used within the scope. Applicability, rounding and calculation rules are defined in `assessment/scoring-model.md`.

---

# 7. Identify Gaps

Identify areas where:

• controls are missing  
• implementation is incomplete  
• risks are not addressed  

These gaps represent improvement opportunities.

---

# 8. Define Improvement Actions

Define concrete actions to improve cybersecurity.

Examples:

• implement missing controls  
• improve processes  
• introduce monitoring  
• strengthen governance  

---

# Optional: Prepare for ACP Certification

Organizations may use the self-assessment to prepare for an official ACP assessment.

Before requesting certification:

• ensure the overall ACP score is at least 2.00  
• ensure every applicable critical domain scores at least 2.00  
• ensure no knock-out control (4.3, 4.4, 5.3, 8.4, 8.5, 9.4) is scored 0  
• collect complete evidence  

---

# Continuous Improvement

Cybersecurity is an ongoing process.

Organizations should:

• repeat assessments periodically  
• track improvements  
• update controls as needed  

---

# Summary

The ACP self-assessment enables organizations to:

• understand their cybersecurity maturity  
• identify weaknesses  
• improve security systematically  
• prepare for certification  

The ACP framework is designed to be practical, structured, and applicable to organizations of any size.
